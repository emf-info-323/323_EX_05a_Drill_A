# 323_EX_Drill_A


Faire une première série d'exercices de "drill" **super simples**, **qui mettent en confiance**, avec un set de questions uniquement :
- 3-4x avec filter() pour ne conserver que les données souhaitées (uniquement évaluations avec notes insuffisantes, uniquement les villes du canton de Fribourg, ...)
- 3-4x avec map()
- 3-4x avec reduce()

Et une dizaine de questions "multi" assez simples quand-même, le but étant de les mettre en confiance et les faire tester par eux-même !
